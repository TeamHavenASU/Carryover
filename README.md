# Skill cards

A skill card teaches one base skill that a task step assumes (First Place, Nov 4: clear steps don't help if someone doesn't have the base skill).

- One file per skill. Task steps list the skills they need in `base_skills`.
- A card can be used by many tasks (`used_by`).
- When a card shows, and how it fades: `definitions.json` -> `skill_cards`.
- 2-4 steps, plain words, one action each. No brands, no money advice, no medical advice.
- New cards can be written by the AI (Role D) but a person must approve them before anyone sees them.
