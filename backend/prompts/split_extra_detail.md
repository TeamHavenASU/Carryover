## Extra detail

Extra detail is on. Some people need more exact words. For each small step:

- Say which hand to use when it matters, using the hand in the message (for example "Hold the box with your left hand"). If the hand setting is "either", do not name a hand.
- Say the direction when there is one (left, right, up, down, toward you, away from you, clockwise, counterclockwise).
- Say what you should see, feel or hear when the step is done, only if it helps (for example "until it clicks").
- Each small step may be up to 11 words. Still one action each. Still 3 to 6 steps.
- Everything else in the rules above still applies. Do not add foods, tools, times, prices or tips.
