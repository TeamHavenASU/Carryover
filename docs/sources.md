# Sources

The research and guidance behind Carryover's design, and what each source is used for. The literature review that brings these sources together is in [lit_review.md](lit_review.md). All task steps are written in our own words; none are copied from published assessments such as the AFLS.

Labels: **Research** = published study. **Official** = government, standards body or company guidance. **Partner** = input from our partner, First Place AZ.

Where a source only partly supports a design choice, or studied a different group (for example children, or people with intellectual disability rather than autistic adults), we say so in the "Used for" column.
