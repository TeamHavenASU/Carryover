# Sources

What each source is used for in Carryover. All task steps are written in our own words. Nothing is copied from AFLS.

Labels: **Research** = published study. **Official** = government, standards body or company guidance. **Ours** = our own choice, with the reason, to test in a pilot.

The team's shared copy (with the same content) is the "Carryover: Literature Review & Sources" doc. Keep the two the same.
