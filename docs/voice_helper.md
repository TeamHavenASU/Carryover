# Voice helper

What it is: a microphone button and an "i" button in the top bar of every page, and on the first Carryover page. It does what the buttons do, by voice. The "i" button explains how it works.

How it turns on: tap the microphone once. The browser asks for permission first (allow once, or while visiting the site). After that it listens from page to page until it is tapped again, or after 3 minutes with nothing said. It shows no transcript and no pop-ups while listening. The page simply does what was asked.

What it does: it presses any button or choice whose words are spoken (continue, next, skip, sky, slow, heat a meal) and also understands actions: next step, show the small steps, read it again, pause, play, I need help, take a break, go home, my tasks, settings, go back, all steps, open a task by name or number. The wording does not have to be exact, and it uses the browser's best few guesses at the words. If an action needs the person to be somewhere else, it takes them there first. While the app is reading a step aloud, only short control words (pause, play, read again, help, break) are accepted, so the reading does not trigger commands.

It never marks a step done on its own. When someone says next or done on a step, it asks "Did you finish this step?" out loud and shows Yes and Not yet. Only a yes (spoken, or the Yes button) runs the normal Done button, so the data logged is the same as a tap. It never presses buttons that change or erase things, such as Redo first-time setup or Reset.

Privacy: while the microphone is on, the browser listens and turns the voice into words. Carryover does not record or keep the audio. In Chrome the speech service is Google's, so the audio goes to Google. Safari uses Apple. The browser shows when the microphone is on, the icon shows it is on, it turns off by itself after 3 minutes of nothing said, and this is explained in the "i" panel.

Limits: it needs Chrome or Safari and a microphone. It is a fixed set of commands with flexible wording, not an AI model. A later version could use an AI model with the resident's consent.
